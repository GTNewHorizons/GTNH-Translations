# 커버 변경 사항
GregTech 기계와 해당 파이프 및 케이블 모두에서 <Color id="GREEN">커버</Color> 사용에 몇 가지 변경 사항이 적용되었습니다. 아래에 설명되어 있습니다

# 기계의 커버 부수기
때로는 가장 작은 변경이 가장 크게 느껴질 수 있습니다!

커버가 부착된 블록을 부술 때 Shift를 누르고 있으면 이제 커버가 드롭됩니다. 그냥 부수는 경우에는 기존 동작이 유지됩니다

# 염색된 유리 커버
파이프와 기계에 **염색된 유리**(또는 다른 반투명 커버)를 추가할 수 있기를 바란 적이 있습니까? 이제 가능합니다!

좋아하는 색상의 염색된 유리로 AE2 외장을 제작한 뒤 다음 위에 배치하십시오:
- 파이프
- 케이블
- 프레임
- 기계
