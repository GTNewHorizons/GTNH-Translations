# 개인 차원 꾸미기
잔디밭에 기반을 두는 것에 지치셨습니까, 아니면 심연의 공허 위에 떠 있는 것에 지치셨습니까? 이제 <Color id="GREEN">개인 차원 포털</Color>이 새롭게 디자인되어 제공되며, "도시 블록" 스타일 프리셋까지 포함합니다!

## 새로운 기능:
- 새롭게 바뀐 인터페이스 디자인!
- 생성되는 지형의 미리보기
- 설정 목록에 있는 블록의 메타데이터 허용
- 차원 생성 시 사용할 수 있는 기능 확장
- __100개 이상의 장식 블록 프리셋__과 완전히 새로운 지형 프리셋이 추가되었습니다.

재미있거나 멋지거나, 아니면 완전히 엉뚱한 디자인을 <a href="https://discord.gg/gtnh">discord</a>에 자유롭게 게시해 주십시오!
