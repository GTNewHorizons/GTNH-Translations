# 공허 채굴기 필터링

공허 채굴기 배열을 필터링하기 위해 특정 광석을 입력 버스에 추가하는 과정이 지루하다고 느끼신 적이 있습니까?

이제 공허 채굴기 자체 내의 단일 UI를 통해 이 모든 것을 처리할 수 있습니다!

새 인터페이스를 열면 현재 차원의 드롭 풀에서 각 광석을 필요에 따라 토글할 수 있습니다. 이 변경 사항은 다음 기능도 추가합니다:
- 성가신 낡은 스크루드라이버를 사용하지 않고 블랙리스트와 화이트리스트 모드 사이를 전환할 수 있습니다
- <Color id="GREEN">데이터 스틱</Color>을 사용하여 필터 구성을 복사하고 불러올 수 있습니다
- 이름으로 광석을 검색하고 강조 표시할 수 있습니다
- 특정 버튼을 통해 __모든__ 광석을 추가하거나 제거할 수 있습니다

> [!NOTE]
> 이 새로운 UI는 기존 설정과 완전히 호환됩니다. 입력 버스에 있는 광석 __또는__ UI에서 선택된 광석이 필터링됩니다
