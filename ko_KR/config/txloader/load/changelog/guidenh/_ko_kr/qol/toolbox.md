# 현장 엔지니어의 공구함
여러 요소를 통합하기 위한 변경의 일환으로, 이제 새롭고 개선된 &lt;Color id="GREEN"&gt;현장 엔지니어의 공구함&lt;/Color&gt; &lt;ItemImage id="gregtech:gt.Item_Toolbox" /&gt;이 추가되었습니다.

이것은 IndustrialCraft2 공구함을 직접 업그레이드한 버전이며, 다양하고 흥미로운 새 기능이 많이 포함되어 있습니다!

모든 도구를 위한 전용 슬롯과 이동 중 충전할 수 있는 전용 배터리 슬롯이 함께 제공됩니다! 배터리가 들어 있기만 하면 기계에서 공구함 전체를 한 번에 충전할 수도 있습니다.

손에 두고 싶은 무엇이든 넣을 수 있는 추가 슬롯이 여섯 개 있습니다! &lt;Color id="BLUE"&gt;납땜 인두&lt;/Color&gt;는 이 슬롯에서 납땜 재료를 가져옵니다.

_&lt;KeyBind id="key.pickItem" /&gt;_ (기본값: 마우스 가운데 버튼)를 누르면 방사형 메뉴가 열리고 도구를 선택할 수 있습니다. 이렇게 하면 _공구함에서 도구를 꺼내지 않고도_ 사용할 수 있습니다. 공구함은 해당 도구를 장착한 것처럼 작동하며, 모든 내구도 피해와 전력 소모는 사용 중인 도구에 직접 적용됩니다!

적절한 도구가 필요한 블록을 바라보면서 _&lt;KeyBind id="key.pickItem" /&gt;_ (기본값: 마우스 가운데 버튼)를 누르면, 해당 도구가 보관되어 있을 경우 방사형 메뉴를 건너뛰고 그 도구를 장착합니다! 예를 들어 &lt;Color id="GREEN"&gt;주석 케이블&lt;/Color&gt;을 바라보고 있으면 보관 중인 전선 절단기를 장착합니다.

정비 해치를 우클릭하면 기존 IC2 공구함과 같은 방식으로 수리합니다.

프로그래머블 회로 &lt;ItemImage id="gregtech:gt.integrated_circuit" /&gt;를 교체할 때는 장착되어 있지 않더라도 공구함에서 드라이버를 찾습니다!

"모드"가 있는 도구(예: 렌치의 &lt;Color id="BLUE"&gt;직선 모드&lt;/Color&gt;)는 도구가 장착되어 있기만 하면 공구함 자체에서 전환할 수 있습니다
