# 도구 개편
이 팩의 일부 도구는 더 많은 관심과 애정을 받았으며, 필요한 곳에서는 기능이 확장되었습니다!
## 메커니즘 변경 사항:
- <Color id="RED">전기 전선 절단기 </Color> <ItemImage id="gregtech:gt.metatool.01:120"/>는 더 이상 EV에 제한되지 않으며, 새로운 LV-MV 변종이 추가되었습니다! 
- <Color id="GREEN">전기 줄 </Color> <ItemImage id="gregtech:gt.metatool.01:204"/>는 더 이상 HV에 제한되지 않으며, 새로운 LV-MV 변종이 추가되었습니다! 
- <Color id="BLUE">착암기</Color> <ItemImage id="gregtech:gt.metatool.01:130"/>는 더 이상 HV에 제한되지 않으며, 새로운 LV-MV 변종이 추가되었습니다! 
- 모든 도구는 나트륨, 카드뮴, 리튬 배터리 변종으로 제작할 수 있습니다. 내부 EU 저장량은 배터리 크기를 반영합니다.
- 일부 도구에는 일관성을 위해 더 많은 재료 옵션이 추가되었습니다. 새로운 옵션을 찾을 수 있는지 확인해 보십시오!
- <Color color="#00ffff">고무 망치</Color>에는 순환 가능한(토글/켬/끔) 모드가 추가되어 대규모 기계 그룹을 확실하게 다룰 수 있습니다.

## 텍스처 변경 사항:
- LV-HV 변종이 있는 모든 도구(납땜 인두 제외)는 제작에 사용된 재료에 맞게 기본 색상이 지정됩니다.
- 특수 재료로 제작된 모든 도구는 이제 해당 재료를 반영하는 애니메이션이 포함된 전용 세트를 가집니다! <ItemImage id="gregtech:gt.metatool.01:100:{GT.ToolStats:{PrimaryMaterial:Infinity,SpecialData:-1L,MaxDamage:262144000L,Tier:1L,Mode:0b,MaxCharge:100000L,Voltage:32L,Electric:1b,SecondaryMaterial:Steel}}" />
