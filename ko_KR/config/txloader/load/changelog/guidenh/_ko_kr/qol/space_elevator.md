# 우주 엘리베이터 변경 사항
몇 가지 멋진 편의성 개선 사항이 <Color id="GREEN">우주 엘리베이터</Color> <ItemImage id="gregtech:gt.blockmachines:14003"/>에 적용되었습니다.

# 우주 엘리베이터 입력 공유
생산량을 늘리기 위해 <Color id="BLUE">우주 엘리베이터</Color>를 몇 대 더 추가하고 싶으셨지만, 연산을 리다이렉트하는 것이 번거롭다고 느끼신 적이 있으십니까? 이제 우주 엘리베이터의 __모든__ 채굴 모듈 간에 연산과 플라즈마를 공유할 수 있습니다!

모듈 간 연산 및/또는 플라즈마를 정밀하게 조정하고 싶으시다면, 이전과 마찬가지로 해당 모듈에 해치를 설치하면 여전히 가능하며, 주어진 양의 자원만 사용합니다.

> [!NOTE]
> 이 기능은 채굴 모듈에만 적용되며, 우주 조립기와 펌프는 이 기능과 함께 작동하지 않습니다.
> 기존 설비는 이전과 마찬가지로 계속 작동합니다.

# 우주 채굴기 GUI 개선 사항
<FloatingImage src="../assets/qol/space_gui.png" align="left" wrap="square" displayWidth="128">
  <ImageAnnotation>
    새로운 <Color id="RED">우주 채굴기 유틸리티</Color> 패널
  </ImageAnnotation>
</FloatingImage>
<Color id="GREEN">우주 채굴 모듈</Color>의 인터페이스가 대폭 업데이트되어, 스프레드시트와 같은 게임 외부 자료를 참고해야 할 필요성이 크게 줄어들었습니다!

UI에 3개의 새로운 패널이 추가되었습니다:
- <Color id="BLUE">우주 채굴기 계산기</Color>: 티어와 거리 설정이 주어졌을 때 특정 구성이 어떤 결과를 낼 수 있는지 확인할 수 있습니다!
- <Color id="RED">우주 채굴기 유틸리티 패널</Color>: 모든 다양한 소행성을 볼 수 있으며, 주어진 거리, 채굴기 티어, 또는 드론 티어에서 어떤 소행성을 타격할 수 있는지 빠르게 확인할 수 있습니다.
- <Color color="#00ffff">소행성 정보 패널</Color>: 소행성에 대한 모든 관련 정보를 보여주며, 특정 소행성을 최대한 자주 타격할 수 있도록 채굴기 거리를 자동으로 설정하여 해당 소행성을 목표로 삼을 수 있게 해줍니다!

현재 채굴 가능한 모든 것이 필터에서 강조 표시되므로, 무엇이 사용 가능한지 한눈에 볼 수 있습니다!
