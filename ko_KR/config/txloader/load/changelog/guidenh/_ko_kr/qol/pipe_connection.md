# 파이프 즉시 연결
긴 파이프라인을 연결해야 하는데, 파이프를 설치한 뒤 실제로 연결이 등록되기까지의 어색한 지연 때문에 답답했던 적이 있으십니까? 이제 더 이상 울 필요가 없습니다!

모든 GregTech 유체 파이프 <ItemImage id="gregtech:gt.blockmachines:30729" />, 아이템 파이프 <ItemImage id="gregtech:gt.blockmachines:5633" />, 그리고 케이블 <ItemImage id="gregtech:gt.blockmachines:1211" />은 이제 명시적으로 연결한 모든 블록에 즉시 연결됩니다 (예: 블록/파이프/케이블 위에 직접 설치하는 경우).
> [!NOTE]
> 걱정하지 마십시오. 파이프를 해당 파이프 위에 명시적으로 설치하지 않는 한, 인접한 어떤 파이프에도 _즉시 연결되지 않습니다_.
