# Freecam
이제 2.9 버전에서는 Freecam 모드가 있습니다! 최신 건축물을 자랑할 완벽한 각도를 원하는 과시형 플레이어들에게 안성맞춤입니다!

## 기능:
- 크리에이티브 및 고정(드리프트 없음) 이동 옵션
- 카메라 히트박스가 반 블록보다 작아서 반 블록 아래에도 들어갈 수 있습니다
- <Color id="GREEN">삼각대 시스템</Color>: _전환_ 버튼을 누른 상태에서 숫자 키를 누르면 카메라 위치를 저장할 수 있습니다
- 네 가지 충돌 모드:
- - 전체
- - 투명 무시(불투명하지 않은 블록)
- - 열 수 있는 블록 무시(문, 다락문 등)
- - 없음(노클립)
- 풀브라이트, 안개 제거, 손 렌더링, 초기 시점에 대한 설정 옵션

## 기본 조작:
- F4 - Freecam 전환(현재 바인딩: <KeyBind id="key.freecam.toggle"/>)
- F4 + 1-9 - <Color id="GREEN">삼각대</Color> 슬롯 열기 또는 전환(현재 바인딩: <KeyBind id="key.freecam.toggle" /> + 1-9)
- F4 + C - 플레이어/카메라 조작 전환(현재 바인딩: <KeyBind id="key.freecam.playerControl" />)
- F4 + R - 모든 <Color id="GREEN">삼각대</Color> 초기화(현재 바인딩: <KeyBind id="key.freecam.resetTripods" />)
- 마우스 휠 스크롤 - 비행 속도 조절
> [!NOTE]
> 서버 관리자는 충돌 모드를 강제하거나 플레이어에게서 모드를 완전히 비활성화할 수 있습니다
