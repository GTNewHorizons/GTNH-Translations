# InGame Info 전환
<Color id="GREEN">InGame Info</Color> (기본적으로 왼쪽 위에 표시되는 정보)가 이제 두 번째 설정 파일을 지원합니다!

즉, 서로 다른 두 가지 HUD 레이아웃을 유지하고 게임 내에서 언제든지 둘 사이를 전환할 수 있습니다!

선택적으로 두 번째 파일(`\config\InGameInfo2.xml`)을 추가한 다음, 토글 키를 사용해 순환하십시오: 기본 -> 보조 -> OFF!
