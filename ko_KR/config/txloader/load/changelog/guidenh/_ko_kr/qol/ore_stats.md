# 광석 변경 사항
광석이 생성되고 플레이어가 상호작용하는 방식에 몇 가지 좋은 변경 사항이 있습니다! 아래에 설명되어 있습니다.
# 광석 통계 페이지
<FloatingImage src="../assets/qol/vein_stats.png" align="left" displayWidth="128" wrap="square">
  <ImageAnnotation>
    새로운 "광맥 통계" 페이지
  </ImageAnnotation>
</FloatingImage>
NEI의 <Color id="GREEN">광맥 통계</Color> 페이지가 멋지게 개편되었습니다! 이는 "광맥 통계", "소형 광석 통계", "지하 유체 통계" 페이지를 포함합니다.

새로운 디자인과 함께, 광석이 포함된 세계 위에 마우스를 올리면 해당 세계의 광석 청크당 광맥이 생성될 확률을 보여줍니다!

새 페이지는 이전 디자인에 있던 동일한 정보를 여전히 유지하지만, GUI 스케일이 허용한다면 이제 일반 페이지 안에서 하나 이상의 광맥 유형을 표시할 수 있습니다.

__BartWorks__ 같은 곳의 광석도 동일한 시스템을 사용하도록 리팩터링되었습니다. 더 이상 어떤 광석을 검색하는지에 따라 이상한 동작이 발생하지 않습니다.

# 광석 생성 변경 사항
- <Color id="GREEN">Bartworks</Color>와 <Color id="RED">GT++</Color>에서 생성되는 광석이 이제 GregTech 광맥이 생성되는 방식을 모방하도록 개편되었습니다.
- 소행성은 더 흔해졌지만, 이를 보완하기 위해 이제 더 작아졌습니다.
- 새로운 <Color color="#DBF1FD">얼음 소행성</Color>이 소행성대에 추가되었습니다.
- 광맥이 이제 공기에 의해 지워질 가능성이 줄어들었습니다.
- 누락되었던 일부 광맥이 찾기 편의와 일관성을 위해 NEI에 추가되었습니다.
