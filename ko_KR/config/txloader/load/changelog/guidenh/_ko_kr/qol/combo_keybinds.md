# 조합 키 바인드
모든 키 바인드를 한 번에 설정해 두는 것을 좋아하지만, NUMPAD= 같은 이상한 버튼에 의존해야 하는 것은 싫으십니까? 더 작은 키보드를 사용하는데 새로운 옵션을 모두 따라가기에 키가 충분하지 않으십니까?

이제 조합 키 바인드가 있으니 이 모든 것은 과거의 일이 되었습니다! 이것은 한 번에 가질 수 있는 __합리적인__ 키 바인드의 수를 엄청나게 늘려 줍니다!
