# GTNH 팀
2.9에 새 팀 시스템이 도입되었습니다. 하지만 아직 성급하게 반발하지는 마십시오! 이 시스템은 현재 팩에 있는 사실상 모든 팀 시스템을 대체하는 것을 목표로 합니다!

모든 플레이어는 기본적으로 팀(자신만으로 구성된 팀)에 속하게 되며, 표준 명령어는 이 페이지 끝에 나열되어 있습니다. 이 팀 시스템은 현재 [자판기](../qol/vending_machine.md) 및 [Visual Prospecting](../qol/shared_prospecting.md)과 함께 작동하지만, 개발팀은 서로 다른 기존 팀 시스템이 난립하는 것을 피하기 위해 모든 것을 천천히 이 시스템으로 이전하려고 작업 중입니다.

## 명령어:
| 명령어   | 용도    |
|--------------- | --------------- |
| `/gtnhteam help`   | 이 명령어 목록을 표시합니다   |
| `/gtnhteam info`   | 현재 팀의 멤버 목록을 출력합니다   |
| `/gtnhteam invite <player>`   | 관리자 - 온라인 플레이어를 팀에 초대합니다   |
| `/gtnhteam accept [team]`   | 대기 중인 팀 초대를 수락합니다  |
| `gtnhteam deny [team]`   | 대기 중인 팀 초대를 거절합니다 |
| `gtnhteam leave`   | 현재 팀을 떠나 새로운 단독 팀을 만듭니다 |
| `gtnhteam rename <new name>`   | 소유자 - 팀 이름을 변경합니다 |
| `/gtnhteam promote <player>`   | 소유자 - 멤버를 관리자로, 또는 관리자를 소유자로 승진시킵니다 |
| `/gtnhteam demote`   | 소유자 - 소유자를 관리자로, 또는 관리자를 멤버로 강등시킵니다 |
