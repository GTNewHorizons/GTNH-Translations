# 아크 용광로 변경 사항
2.9의 일부로, <Color id="GREEN">아크 용광로</Color>와 관련된 전체 시스템이 변경되었습니다. 이제 [산업용 아크 용광로](../reworks/industrial_arc_furnace.md)가 있을 뿐만 아니라, 싱글블록 기계에 다음과 같은 변경 사항이 적용되었습니다:

- 싱글블록 플라즈마 아크 용광로는 이제 <Color id="RED">__사용 중단됨__</Color>이며, 해당 레시피 맵은 일반 아크 용광로에 통합되었습니다.
- 연철은 __주철__ <ItemImage id="gregtech:gt.metaitem.01:13304"/>로 이름이 바뀌었고, 이제 탄소를 사용합니다.
- 강철은 이제 모든 상황에서 제작 시 석탄이 필요합니다.
- 모든 레시피에는 이제 __비활성 기체__를 사용하는 대체 레시피가 있습니다(EBF와 동일한 스케일링 적용).
- 네더라이트 레시피는 전반적으로 티어가 낮아졌습니다.
- 만성 특이점 레시피는 티어가 낮아졌습니다.
