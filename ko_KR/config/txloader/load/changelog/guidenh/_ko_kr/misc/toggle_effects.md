# 효과 전환
작은 변경이지만, 그럼에도 반가운 기능입니다!

인벤토리 효과 아이콘은 이제 Hodgepodge 옵션 -> 조정 아래에 있는 `showInventoryEffectIcons`를 사용하여 전환할 수 있습니다! 이 기능은 물약 효과를 표시하는 인벤토리 배너가 너무 복잡하게 느껴질 경우, 해당 배너를 켜거나 끕니다!
