# 퀘스트 완료 추적기
퀘스트북은 이제 완료한 퀘스트의 총 개수와 완료율을 표시합니다! 챕터 완료 문구에도 비슷한 완료율이 표시됩니다! 구체적으로, 일부 "숨겨진" 퀘스트나 즉시 볼 수 없는 항목은 일반적으로 추적하지 않습니다.
