# 월드 선택 개선
월드 저장 파일은 이제 스크린샷을 캡처하여 월드 목록에 아이콘으로 표시합니다! 월드를 불러올 때 스폰 청크가 생성되는 동안 청크 컬러맵 격자가 포함된 진행 표시줄을 보여줍니다. 월드 선택 화면에는 이제 이름이나 심지어 폴더로 필터링하는 검색창도 있습니다!
