# CPU 정렬
CPU를 이름으로만 정렬해야 하는 제한 없이 정렬하고 싶으셨습니까? 이제 가능합니다!

이제 CPU는 다음과 같은 다양한 기준으로 정렬할 수 있습니다:
- CPU 이름
- 저장 메모리
- 보조 프로세서 수
- 제작 상태
- 자동화(플레이어, 혼합, 비플레이어)

또한 이러한 범주 중 어느 것이든 오름차순 또는 내림차순으로 정렬할 수 있습니다!
