# 네트워크 시각화 도구
이전에 게임을 충분히 멀리까지 진행해 보셨다면, 네트워크 시각화 도구 <ItemImage id="appliedenergistics2:item.ToolNetworkVisualiser"/>가 읽을 수 없는 선들이 뒤엉킨 엉망진창이 되기 시작한다는 점을 아실 것입니다.

이를 돕기 위해 렌더링이 이제 변경되었습니다! 변경 사항은 `config/ae2stuff.cfg`에서 또는 AE2Stuff의 인게임 설정을 통해 완전히 설정할 수 있습니다!
