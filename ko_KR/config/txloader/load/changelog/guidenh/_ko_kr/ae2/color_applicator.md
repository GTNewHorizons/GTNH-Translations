# 색상 적용기 GUI
P2P 터널에 색상 코드를 지정하려고 시프트 스크롤을 하다가 목표 색상을 세 번 연속 지나쳐 지치셨습니까? 아니면 전력선에 사용한 회색 음영을 잊으셨습니까?

<Color id="GREEN">AE2 색상 적용기</Color><ItemImage id="appliedenergistics2:item.ToolColorApplicator"/>에 새로운 GUI 업그레이드가 추가되었습니다!

이제 도구로 시프트 우클릭을 하면 모든 색상과 각 색상별로 사용 가능한 염료의 양을 보여 주는 GUI를 열 수 있습니다!

또한 이미 색상이 지정된 AE2 부품을 가운데 클릭하여 해당 색상을 적용기로 즉시 복사할 수 있습니다!
