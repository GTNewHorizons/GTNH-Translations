# Кабельные модули

В AE2 определённые [устройства](devices.md) и компоненты можно размещать на кабелях в пределах одного блока. Это полезно для создания компактных схем.
Нажатие Shift+ПКМ с помощью <ItemLink id="appliedenergistics2:item.ToolCertusQuartzWrench" showIcon="left" /> или <ItemLink id="appliedenergistics2:item.ToolNetworkTool" showIcon="left" /> позволяет снять отдельный модуль
 (или сам кабель), не ломая всё содержимое этого блока.
