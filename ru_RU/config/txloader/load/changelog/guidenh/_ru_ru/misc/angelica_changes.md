# Изменения Angelica
Для тех, кто не в курсе: <Color id="GREEN">Angelica</Color> - это замена Optifine в GTNH, которая улучшает рендеринг во всех аспектах и обеспечивает встроенную совместимость с шейдерами!

Этот мод не новый, но в 2.9 есть некоторые изменения! Здесь не описаны большие объёмы работы по общей оптимизации рендеринга и исправления ошибок.

## Compact CTM
Этот раздел для разработчиков текстур! Возможно, вы не знали, но раньше для того, чтобы стекло выглядело красиво, требовалось <Color id="RED">47</Color> уникальных текстур! Angelica изменила это благодаря встроенной поддержке <Color id="GREEN">Compact CTM</Color>. Теперь для каждого блока нужно создать всего 5 файлов, то есть работы стало в 9 раз меньше, а места на диске занимает почти в 10 раз меньше, и при этом визуальное качество не страдает.
