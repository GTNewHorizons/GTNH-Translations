# Команды F3
В версии 2.9 почти все команды F3 получили переводимые отладочные сообщения. Кроме того, из современных версий портировали сочетания клавиш F3 + Q и F3 + D - они открывают список всех комбинаций отладки и очищают чат соответственно.
