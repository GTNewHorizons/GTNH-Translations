# Наложения заголовков
В версии 2.9 часть функций отображения текста заголовков и подзаголовков была перенесена в 1.7.10 для использования в GTNH! Администраторы серверов теперь могут выводить текст заголовков и подзаголовков на экраны игроков с помощью команды `/title`. Это также полностью совместимо с кодами [системы цветов](./color_system.md), которые можно использовать в чате!

Заголовки также могут плавно появляться, удерживаться на экране и затухать с настраиваемым временем через команду `/title <player> times <fadeIn> <stay> <fadeOut>`.
