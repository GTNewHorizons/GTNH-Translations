# Наложения заголовков
Новинка в 2.9: часть текстовых выводов заголовка и подзаголовка перенесена на 1.7.10 для использования в GTNH! Администраторы серверов теперь могут выводить текст заголовка и подзаголовка на экраны игроков с помощью `/title`. Это также полностью совместимо с кодами [системы цветов](./color_system.md), которые можно использовать в чате!

Заголовки также могут плавно появляться, оставаться на экране и плавно исчезать с настраиваемым временем через `/title <player> times <fadeIn> <stay> <fadeOut>`
