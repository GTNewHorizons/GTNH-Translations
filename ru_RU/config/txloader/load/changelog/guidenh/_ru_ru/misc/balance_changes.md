# Изменения баланса
Как и в любом крупном обновлении, большое внимание было уделено тому, чтобы сделать сборку интересной и богатой на варианты прохождения. Это часто влечёт за собой множество балансных правок, призванных сделать более слабые варианты жизнеспособными, а "слишком сильные" - менее доминирующими.
> [!NOTE]
> Полный список изменений баланса слишком велик и субъективен, чтобы приводить его здесь, поэтому он не включает такие вещи, как стоимость мультиблоков (по крайней мере, в плане структуры) или добавление новых веток, которые напрямую влияют на баланс (например, [CropsNH](../crops/crops.md)). Из-за огромного количества балансных правок единственный реальный способ узнать КАЖДОЕ изменение - просмотреть список изменений на GitHub пункт за пунктом. Поэтому приведённый ниже список - лишь выборочная подборка некоторых наиболее крупных изменений версии 2.9.

- Мега ректификационная колонна (HV -> LuV), Мега установка крекинга нефти (HV -> LuV), Мега электрическая доменная печь (теперь Экзотермический горн) (HV -> ZPM), Мега вакуумный морозильник (теперь Эндотермический морозильник) (HV -> ZPM)
- Гипоген (UIV -> UEV), обработка в Оке гармонии теперь требует вольтаж UXV
- Рецепт тетрахлорида титана на основе титана (10с HV -> 60с EV)
- Ряд [переработок структур](../reworks/reworks.md), вносящих различные балансные изменения
- Криотеум теперь использует лазуритовую пыль вместо красной пыли
- Новые рецепты для водонапорной башни Railcraft
- MV генератор поля теперь требует титан вместо вольфрамовой стали
- Базовые рецепты SMD теперь требуют HV сборочную машину вместо MV
