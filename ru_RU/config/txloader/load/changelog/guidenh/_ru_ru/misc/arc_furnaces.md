# Изменения дуговой печи
В версии 2.9 вся система, связанная с <Color id="GREEN">дуговыми печами</Color>, была переработана. Помимо появления [промышленной дуговой печи](../reworks/industrial_arc_furnace.md), одноблочные механизмы получили следующие изменения:

- Одноблочные плазменные дуговые печи теперь <Color id="RED">__УСТАРЕЛИ__</Color>, а их карта рецептов объединена с обычной дуговой печью
- Кованое железо переименовано в __чугун__ <ItemImage id="gregtech:gt.metaitem.01:13304"/> и теперь требует углерод для производства
- Сталь теперь при любых условиях требует уголь для создания
- Все рецепты теперь имеют альтернативные варианты с __благородными газами__ (с таким же масштабированием, как у EBF)
- Рецепты незерита были понижены по тиру во всех случаях
- Рецепт хронической сингулярности был понижен по тиру
