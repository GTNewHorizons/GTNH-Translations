# Улучшения выбора мира
Сохранения миров теперь делают скриншот и отображают его в виде значка в списке миров! При загрузке мира отображается шкала прогресса с цветовой сеткой чанков по мере генерации чанков спавна. На экране выбора мира также появилась строка поиска, позволяющая фильтровать миры по названию или даже по папке!
