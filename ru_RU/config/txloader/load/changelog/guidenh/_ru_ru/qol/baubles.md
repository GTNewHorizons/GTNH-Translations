# Baubles
Чтобы упорядочить инвентарь, вкладка инвентаря Tinker's отключена. Взамен добавлено следующее:

- Добавлены новые <Color id="GREEN">__универсальные__</Color> слоты baubles, которые принимают _большинство_ украшений в игре

- Добавлена возможность помещать предметы Tinker's в слоты Baubles:
- - <Color id="GREEN">Поясная сумка</Color> - тип слота: универсальный
- - <Color id="RED">Перчатка путешественника</Color> - тип слота: универсальный
- - <Color id="BLUE">Банки с сердцами</Color> - особые слоты, которые складываются стопкой до 10 штук!

- Возможность надевать факелы и блоки перенесена в <Color id="GREEN">Пользовательскую косметическую броню</Color>. Теперь можно с удовольствием носить шляпу из земли! Это также работает с <Color id="GREEN">Динамическим освещением</Color>
