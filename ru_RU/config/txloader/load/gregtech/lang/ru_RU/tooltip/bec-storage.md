Хранимый конденсат становится доступен всем массивам наблюдения текущей сети.
Маршрутизацию конденсата можно контролировать с помощью {gold:{item:gregtech:gt.blockmachines:15760}}.
{dark_gray:{hr}}
Ёмкость хранилища определяется напряжённостью поля.
Напряжённость поля настраивается в интерфейсе. Также её можно задать с помощью компьютера.
{gold:1} единица напряжённости поля хранит {gold:1Л} конденсата и потребляет {gold:1} EU/t.
Если в сети присутствует несколько полей сдерживания, подаваемый конденсат распределяется пропорционально их ёмкости.
{dark_gray:{hr}}
Избыточный конденсат можно поместить в поле сдерживания, но он будет быстро {red:{underline:уничтожен}}.
Когда поле сдерживания переполнено, {red:{underline:11%}} его конденсата удаляется каждую секунду.
Если поле сдерживания в любой момент отключается, его содержимое будет {red:{underline:уничтожено}}.
