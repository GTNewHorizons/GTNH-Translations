Чтобы подключиться к сети, у мультиблока должен быть {gold:{item:gregtech:gt.blockmachines:15476}}, соединяющийся с кондуитом.
Используйте {gold:{item:gregtech:gt.blockmachines:15760}} для управления потоком конденсата.
