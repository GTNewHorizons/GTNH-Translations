Телепортирует предметы в {gold:{item:gregtech:gt.blockmachines:15756}} и обратно.
Логика рецептов такая же, как и у всех других мультиблоков.
Для начала рецепта наличие конденсата не обязательно
Свяжите его с {gold:{item:gregtech:gt.blockmachines:15756}} с помощью {gold:{item:gregtech:gt.blockmachines:15481}}.
{dark_gray:{hr}}
Каждый предметный слот в рецепте связан с определённым тиром нанитов.
Чтобы узел телепортации  продвинулся по предметному слоту, он должен получить нанит того же тира или выше.
Избыток нанитов линейно увеличивает скорость выполнения рецептов.
Использование нанита более высокого тира, чем требуется, замедляет прогресс в {italic:2^((provided tier - requested tier)} раз(а).
EU/t этого мультиблока остаётся постоянным, даже когда он на паузе, простаивает или замедлен.
Каждый рецепт, выполняемый параллельно, линейно увеличивает потребление EU/t.
Этот мультиблок не поддерживает разгон.
{dark_gray:{hr}}
Минимальное и максимальное количество параллелей можно настроить в параметрах, чтобы гарантировать точное время выполнения рецепта.
Рецепты можно принудительно замедлить, чтобы компенсировать медленную автоматизацию, с помощью параметра {gold:{lang:GT5U.gui.text.bec-speed-divisor}}.
{dark_gray:{hr}}
{gold:{item:gregtech:gt.blockmachines:15758}} может использоваться для обнаружения нанитов, запрашиваемых узлом телепортации.
{gold:{item:gregtech:gt.blockmachines:15759}} можно использовать для временной приостановки узла телепортации.
