# Angelica Changes
Para quem não sabe, o <Color id="GREEN">Angelica</Color> é o substituto do Optifine no GTNH; ele melhora a renderização de modo geral e oferece compatibilidade nativa com shaders!

Este mod não é novo, mas traz algumas mudanças para a versão 2.9! Isso não inclui o enorme esforço dedicado à otimização geral da renderização, nem as correções de bugs.

## CTM Compacto
Esta é para os desenvolvedores de texturas! Talvez vocês soubessem ou não, mas, anteriormente, eram necessárias <Color id="RED">47</Color> texturas exclusivas só para deixar o vidro com uma aparência bacana! A Angelica mudou isso com suporte nativo ao <Color id="GREEN">Compact CTM</Color>. Agora, basta criar 5 arquivos por bloco — o que significa 9 vezes menos trabalho e quase 10 vezes menos espaço ocupado em disco —, tudo isso sem qualquer perda na qualidade visual.

## Rastreamento de cores avançado
> [!AVISO]
> Isso ainda não foi totalmente implementado no pacote, e o trabalho continua. Mas, ei, o que seria de uma atualização sem uma prévia antecipada da próxima?
Há muito trabalho sendo feito nos bastidores para tornar o <Color id="GREEN">Advanced Color Tracing</Color> o padrão no GTNH. Quem já utiliza algo como o Euphoria Patches provavelmente já conhece, mas $$\text{em breve}^{TM}$$ haverá suporte completo para quaisquer shaders (ou, quem sabe, até mesmo sem eles!)
