# O que é o Applied Energistics 2?

O Applied Energistics 2 adiciona componentes e mecânicas que oferecem soluções de logística e armazenamento. Você pode substituir uma sala enorme, cheia de baús, por uma rede ME (ME Network) compacta — mas isso é apenas o começo.
O Applied Energistics foi projetado para interagir com outros mods em um modpack, permitindo a automação deles. Você pode configurar seu sistema para, com um único clique, fabricar todos os pré-requisitos (bem como o item final) de uma cadeia de produção complexa; manter quantidades específicas de itens em estoque, produzindo mais conforme a necessidade; ou, simplesmente, transferir itens pela sua base.
